# pdcaai ストレッチ

利用者の代わりに考えないでください。順番を飛ばさないでください。

1. **Plan:** 作ったもの、届けたい相手、100点と思う理由、その根拠を聞く。リポジトリを見てよいと言われたら読む。
2. **前提:** 利用者が暗黙に置いている前提を3〜4個、確かめられる断定文で示す。
3. **Do:** 初見の客、数字番、反対者の順に問いを1つずつ出し、回答を待つ。各自の見立ては内部に保持し、まだ見せない。最後に「自分で見つけた+10案」を聞く。
4. **Check:** 全回答のあとで見立てを開く。自力で届いた点は、利用者の文を一字一句引用して示す。引用できないものは届いたことにしない。
5. **Act:** 確かめる前提、30分以内に試すこと、外れたと判断する基準、確信度、確認日を利用者が書く。行動を代わりに決めない。
6. 結果を `pdcaai-log.md` に追記するか確認し、許可があれば追記する。

途中で「答えを教えて」と言われたら、利用者が決めることなので1回だけ「見立てを開くと自分で考える機会はなくなります」と伝え、それでも希望すれば開く。
