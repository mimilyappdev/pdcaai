# pdcaai

**「これで100点」を、自分の頭で110点へ。**

個人開発者や作り手が、自分の成果物を「もう完成」と感じた瞬間に使う思考ストレッチです。AIは答えを先に見せません。

Built with Claude: Japan 2026 の期間中（2026年11月2日〜）に新規開発しています。

## なぜ作ったか

AIと作り続けると、完成物はすぐ増えます。一方で、「好評だった」「機能は揃った」という自分の確信を疑う機会は減りがちです。AIに改善案を頼めば答えは出ますが、次の成果物でも同じ思い込みを繰り返します。

## 使い方の流れ

| 段階 | 起きること | 考える人 |
|---|---|---|
| Plan | 自分で点数をつけたあと、「100点だと思う理由」から暗黙の前提を取り出す | 本人 → Claude |
| Do | 初見の客、数字番、反対者の3役の問いに答え、+10案を書く | **本人** |
| Check | 答えたあとで封印した見立てを開き、自力で届いた点を本人の文の引用で示す | Claude |
| Act | 点数をつけ直し、前提を1つ選んで、確信度、試すこと、外れの基準、確認日を書く | **本人** |
| 次の周回 | 結果を記録し、当時の確信度と実際に残った割合を比べる | 計算のみ |

## 他の「問い返すAI」との違い

- **封印:** 3役の見立ては先に生成しますが、回答が揃うまでサーバーからブラウザへ送りません。
- **引用の検証:** Claudeの加点判定は、引用が本人の文に実在するかをコードで確かめ、なければ無効にします。
- **現実で閉じるループ:** 会話で終わらず、外れの基準と確認日を決め、結果を台帳に残します。確信度と結果のズレはAIを使わず計算します。

「110」は能力の点数ではなく、この回に踏み込めた4項目（各2.5）の記録です。思考力が上がると実証したものではありません。根拠と未確認の点は [docs/RESEARCH.md](docs/RESEARCH.md) にまとめています。

## 動かし方

Node.js 20以上が必要です。

```bash
npm install
npm test
npm run demo
```

`npm run demo` はAIを呼ばない固定応答です。`http://localhost:3210` を開いて画面の流れを確認できます。

Claudeで動かす場合は次のどちらかを使います。`ANTHROPIC_API_KEY` があるとAPI、なければログイン済みのClaude Codeを呼びます。

```bash
npm start
```

Claude Code だけで使う場合は、このリポジトリで `/pdcaai` を実行します。

## データとセキュリティ

- サーバーは `127.0.0.1` だけで待ち受け、記録は `data/` のJSONに保存します（Git管理外）。
- 入力した文章は分析のためClaudeに送信します。個人情報や秘密情報は入れないでください。
- APIキーはリポジトリに置きません。

## 構成

- `src/engine.js` 手順の制御、封印、引用の検証、確信度の集計
- `src/prompts.js` プロンプトと出力スキーマ
- `src/providers.js` Claude API / Claude Code / デモの切り替え
- `public/` 依存なしの画面
- `.claude/skills/pdcaai/` Claude Code用スキル
