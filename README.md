# AIだけじゃダメですか？！（PDCAI）

**AIに引継ぎマニュアルを作らせると、見た目はきれいでも後任が止まる。PDCAI は、人が先に書き、AI社員4人が「書かれていない所」を指し、後任役のAIが実際に止まった場所を返す。頭の中にある、言語化されていない判断を掘り出す Claude Code プラグインです。**

同じ業務の同じ15場面で、AIだけで作ったマニュアルは後任役のAI（Claude 3種・ChatGPT・Gemini）が 75回中58回止まり、PDCAI で3周回した本人の言葉のカードは 19回でした。

AIが作った資料から始めてもかまいません。架空のカフェの見本では、AIだけで作ったマニュアル（8場面中5つで止まった）に、人が自分で考えて書き足すたびに止まる数が減り、最後は0になりました（最後の決めごとは店長役のAI）。

Built with Claude: Japan 2026 の期間中（2026年11月2日〜）に新規開発しています。

## まず試す（3ステップ）

1. [Claude Code](https://claude.com/claude-code) を入れる。
2. プラグインを入れる。

   ```bash
   claude plugin marketplace add mimilyappdev/pdcaai
   claude plugin install pdcaai@pdcaai
   ```

3. Claude Code で、引き継ぎたい仕事や作りかけのものについて「これで完成」「これで作って」と打つ。PDCAI が「先に気になる点を1つ挙げてみますか？」と声をかけます。

観点帳の木と伸びの表、引継ぎカードの画面を見るときだけ、下の「動かし方」で Web アプリを起動します。Claude Code なしでブラウザだけで使える形は、締切後に作る予定です。

## 業務の中身を入れるときの注意

- 書いた内容は、AI社員と後任役のために Claude に送られます。個人名・取引先名・金額など、外に出せないものは伏せて書いてください（「〇〇社」「A社」で十分に回ります）。
- 観点帳は自分の端末の中（`~/.pdcaai/notebook.json`）にだけ保存され、どこにもアップロードしません。
- 引継ぎカードに残るのは本人の言葉だけです。AIの文は「AI社員が補足」として区別し、本人が書くか消すかを決めます。

## なぜ作ったか

AIと作り続けると、完成物はすぐ増えます。一方で、「機能は揃った」という自分の確信を疑う機会は減りがちです。AIに抜けを全部出してもらえば答えは出ますが、次の成果物でも同じところで止まります。pdcaai は、AIに頼り切るのではなく、自分で気づける範囲を広げるためのものです。

- 作者本人の3周の記録と、架空のペルソナによる試験走行: [docs/SIMULATION.md](docs/SIMULATION.md)
- 観点帳の木の色と形の根拠: [docs/kento.html](docs/kento.html)

## Claude Code プラグイン

作り始める・仕上げる瞬間に使うスキルです。本人が先に検討事項を出し、AI社員のサブエージェント4人（新入社員、法務・リスク管理、財務、ユーザー）と突き合わせます。見落とした観点は観点帳（`~/.pdcaai/notebook.json`）に積まれ、自分で出せるようになった観点からヒントが減っていきます。「これで作って」「完成」などの発言にはフックが1回だけ声をかけます。

```bash
claude plugin marketplace add mimilyappdev/pdcaai
claude plugin install pdcaai@pdcaai
```

観点帳は `npm start` のあと `http://localhost:3210/#/notebook` で、一本の木として見られます。周回ごとに幹が上へ伸び、自分の考えは葉、AI社員の気づきはつぼみ、ヒントで広がった考えは花、前に見落とした型を次は自分で出せたものは金の縁で示します。

## Claude の活用

### アプリの中: 役ごとにモデルを使い分け、AIには書かせない

| 役 | 機能・モデル | すること |
|---|---|---|
| 声かけ | フック（UserPromptSubmit） | 「これで作って」「完成」などの瞬間に、先に自分で考えるよう1回だけ一言そえる。止めない |
| 手順 | スキル（pdcaai） | 本人が先に書く → めんだこと突き合わせ → 自分で出せた所からヒントを外す |
| めんだこ4人 | サブエージェント × 4（Sonnet・並列） | 新入社員・法務リスク管理・財務・ユーザーの立場で洗い出す。本人が書いている間に裏で考え、本人の答えは見ない |
| 突き合わせ | Opus | 本人の答えを一字一句引用する。引用が本当にあるかはコードで確かめる |
| 後任めんだこ | Opus | 資料だけを読み、推測で補わずに仕事を試す。止まった所を「あなたが決めること」の問いで返す |
| 清書係 | Opus | 並べ替えと見出し付けだけ。書いていないことは足さない。清書後にもう一度試して確かめる |

返事はすべて JSON Schema（構造化出力）で受け取り、同じコードで Claude Code CLI（`claude -p`）と Claude API を切り替えます。

### 作り方: エンジニアではない作者が、Claude Code に問い返してもらいながら作った

アイデアを出すのは作者、Claude は問い返す相手です。コードは書かなくても、ディレクションは作者がしました。

1. **まず相談する**: 作者が「こういうのどう？」と投げ、Claude が「それならこれは？」と問い返し、作者が方向を決める。Claude が3つの案と、おすすめ・理由・かかる時間を出してから聞くよう、CLAUDE.md に書いた。
2. **目的で機能を選ぶ**: 声かけはフック、手順を守らせるのはスキル、立場ごとに考えるのはサブエージェント。
3. **チャットを分けて並べる**: 台本・動画構成・競合調査・先行研究・提出物・監査を別々のセッションで同時に進め、結果を1つに集めた。監査役の Claude が審査基準で点検した。
4. **自分のアプリで自分を試す**: 動画の案を PDCAI のめんだこ4人に読ませて直した。

アプリ本体、テスト33件、録画の自動操作まで Claude Code で作り、作者一人で6日（最初のコミットは11月3日）で形にしました。

## 会話版（最初に作った形）

以下は、Webアプリで Claude と一言ずつ話す最初の形です。作者が試して「普通にClaudeと話すのと変わらない」と感じたため、上のプラグインの形に進みました。

### 使い方の流れ

| 段階 | 起きること |
|---|---|
| Plan | 最近「これで完成」と思ったものを一言で話し、今の自分の点数をつける |
| Do | Claudeと1問ずつ話す。「わからない」は保留の枝になり、「ヒント」で具体例をもらえる |
| Check | 少し話したあと、封印した見立てを開く。自分で話していた点は発言の引用で示す |
| Act | 会話から作った実験の下書きを自分で直して決め、点数をつけ直す |
| 次の周回 | 結果を記録し、当時の確信度と実際に残った割合を比べる |

最初は文章で回答する形でしたが、作者自身が試して負担が大きかったため、対話の形に作り直しました。

### 他の「問い返すAI」との違い

- **封印:** Claudeの見立ては、開くまでサーバーからブラウザへ送りません。
- **引用の検証:** 枝と加点は、引用が本人の発言に実在するかをコードで確かめます。
- **現実で閉じるループ:** 外れの基準と確認日を決め、結果を台帳に残します。確信度と結果のズレはAIを使わず計算します。

「110」は能力の点数ではなく、この回に踏み込めた4項目（各2.5）の記録です。思考力が上がると実証したものではありません。根拠と未確認の点は [docs/RESEARCH.md](docs/RESEARCH.md) にまとめています。

### 思考ツリー

話すたびに、画面の横に根から枝が育ちます。発見、思考、保留、結論で色が変わり、丸を選ぶと内容の確認と分類の修正ができます。分類を直しても、引用で確認する踏み込みの記録は変わりません。実験の結果からは次の周回の根が伸びます。

## 動かし方

Node.js 20以上が必要です。

```bash
npm install
npm test
npm run demo
```

`npm run demo` はAIを呼ばない固定応答です。`http://localhost:3210` を開いて画面の流れを確認できます。

Claudeで動かす場合は次のどちらかを使います。`ANTHROPIC_API_KEY` があるとAPI、なければログイン済みのClaude Codeを呼びます。

```bash
npm start
```

## データとセキュリティ

- サーバーは `127.0.0.1` だけで待ち受け、会話版の記録は `data/` のJSONに保存します（Git管理外）。
- プラグインの観点帳は `~/.pdcaai/notebook.json` に保存します。リポジトリには入りません。
- 入力した文章は分析のためClaudeに送信します。個人情報や秘密情報は入れないでください。
- APIキーはリポジトリに置きません。

## 構成

- `src/engine.js` 手順の制御、封印、引用の検証、確信度の集計
- `src/prompts.js` プロンプトと出力スキーマ
- `src/providers.js` Claude API / Claude Code / デモの切り替え
- `public/` 依存なしの画面
- `plugin/` Claude Code プラグイン（スキル、AI社員のサブエージェント、フック、観点帳スクリプト）
- `sim/` 架空のペルソナとAI社員を自動で回す試験走行と集計
- `docs/render-tree.mjs` 観点帳の木をSVGに書き出す
