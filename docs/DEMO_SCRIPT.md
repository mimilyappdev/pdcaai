# 3分デモ台本（案）

審査配点: インパクト30%、デモ25%、Claudeの活用25%、深さと実行20%。
実際のClaudeで動かした画面を録画します。**固定応答のデモモードでは本番動画を撮りません。**
イベント中に作った機能だけを映します。

| 時間 | 画面 | 話すこと |
|---|---|---|
| 0:00-0:25 | 本人の実例（タイトルだけ） | 【要記入】自分が100点と思って出して、外れた実話を1つ。 |
| 0:25-0:45 | トップ | AIに聞けば改善案は出ます。でも次も同じ思い込みをします。pdcaaiは答えを先に見せません。 |
| 0:45-1:10 | Plan入力→前提 | 実際の自作物を入れると、Claudeが自分でも気づいていない前提を取り出します。 |
| 1:10-1:45 | 3役の問い→回答 | 3役が同時に問いを作ります。見立ては封印中で、開発者ツールで見てもレスポンスに入っていません。自分の言葉で答えます。 |
| 1:45-2:15 | 開封 | ここで開きます。自力で届いた点は自分の文を引用して示します。引用が実在しなければコードが無効にします。自分だけでは見えなかった点も分かります。 |
| 2:15-2:40 | Act→110 | 最初に100点とつけた作品に、開封後の自分で点をつけ直します。行動も自分で決めます。確信度、外れの基準、確認日を書くと110に届きます。110は能力の点数ではなく、踏み込みの記録です。 |
| 2:40-3:00 | 台帳 | 結果を記録すると、確信度と実際に残った割合のズレが分かります。実際の周回結果を見せて締めます。 |

## 撮影前の準備

1. `claude` にログインするか、APIキーを設定する
2. `npm start` で本番の応答を確認する
3. 実際の自作物で1周回す。公開してよい内容か確認する
4. 開発者ツールのNetworkタブを開いておく
