# 3分デモ台本（案）

審査配点: インパクト30%、デモ25%、Claudeの活用25%、深さと実行20%。
実際のClaudeで動かした画面を録画します。イベント中に作った機能だけを映します。

| 時間 | 画面 | 話すこと |
|---|---|---|
| 0:00-0:20 | 本人の実例（タイトルだけ） | 一人で事業をしています。RakuNovelのテスト版で、長いタイトルを入れると崩れると利用者に指摘されました。思い込みは、気をつけても減りません。 |
| 0:20-0:35 | Claude Code で「これで作って」 | 作り始める瞬間に、フックが一度だけ声をかけます。止めはしません。 |
| 0:35-1:00 | 本人が先に一言ずつ出す | まず自分で出します。AIの答えは、まだ見ません。 |
| 1:00-1:30 | AI社員4人が並列に動く | 新入社員、リスク管理、経理、確認係。私の答えを見ずに、それぞれの立場で洗い出します。 |
| 1:30-2:00 | 突き合わせの結果 | 自分で出せたもの、AI社員だけが気づいたもの、自分だけが気づいたもの。引用が私の答えに実在しなければ、コードが「自分で」と数えません。 |
| 2:00-2:30 | 観点帳の木 | 周回ごとに木が上へ伸びます。花はヒントで広がった考え、金の縁は前に見落とした型を次は自分で出せた印です。 |
| 2:30-3:00 | 3周の記録 | 3周目には、前に見落とした型を、ヒントなしで自分で書けました。補助輪は、自分で出せるようになった観点から外れていきます。AIだけじゃダメですか？ AIに頼り切るのではなく、自分が伸びるための道具です。 |

## 撮影前の準備

1. プラグインを入れる（`claude plugin marketplace add mimilyappdev/pdcaai` → `claude plugin install pdcaai@pdcaai`）
2. 公開してよい題材で1周回す（非公開の事業の内容は映さない）
3. `npm start` で観点帳の木を開いておく
4. 最終日は動画づくりに空ける
