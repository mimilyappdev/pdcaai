# 3分デモ台本（案）

審査配点: インパクト30%、デモ25%、Claudeの活用25%、深さと実行20%。
実際のClaudeで動かした画面を録画します。**固定応答のデモモードでは本番動画を撮りません。**
イベント中に作った機能だけを映します。

| 時間 | 画面 | 話すこと |
|---|---|---|
| 0:00-0:25 | 本人の実例（タイトルだけ） | RakuNovelのテスト版で、長いタイトルを入れると崩れると利用者に指摘された話。自分では気づけませんでした。 |
| 0:25-0:45 | トップ | AIに聞けば改善案は出ます。でも次も同じ思い込みをします。pdcaaiは、話しているうちに自分で気づくためのものです。 |
| 0:45-1:30 | 対話と思考ツリー | 一言で話すだけで、右に枝が育ちます。わからなければ保留の枝になります。見立ては封印中で、開発者ツールで見てもレスポンスに入っていません。 |
| 1:30-2:05 | 開封 | 少し話してから開きます。自分で話していた点は発言を引用して示します。引用が実在しなければコードが無効にします。 |
| 2:05-2:35 | 実験 | 下書きを自分で直して決めます。最初に100点とつけた作品に、点をつけ直します。 |
| 2:35-3:00 | 台帳と次の周回 | 結果から次の枝が伸びます。確信度と実際に残った割合のズレが分かります。 |

## 撮影前の準備

1. `claude` にログインするか、APIキーを設定する
2. `npm start` で本番の応答を確認する
3. 実際の自作物で1周回す。公開してよい内容か確認する
4. 開発者ツールのNetworkタブを開いておく
