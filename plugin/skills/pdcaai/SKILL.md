# pdcaai

AIが検討事項を全部出して終わりにしないでください。本人が先に出し、AIは後から補います。補った見落としは観点帳に積み、次からは本人が自分で出せるようにヒントを減らしていきます。

本人に考えることを強いないでください。一言や「ない」で十分です。1回に聞くことは1つだけにします。

観点帳の操作は、このスキルのフォルダにある `scripts/notebook.mjs` を node で実行します。観点帳は `~/.pdcaai/notebook.json` に保存されます。

## 1. 何を作るか

1つのメッセージで軽く聞きます。

- 作るもの（作ったもの）を一言で
- 今の自信を何%と感じるか

コードや資料があれば場所も聞きます。なければそのままで構いません。

## 2. 先に本人が出す

`node scripts/notebook.mjs hints` を実行しておきます。hints はまだ見せません。

known.said（前回までの本人の答え）があれば、件数と短い一覧を畳んで見せ、「前に言ったことはそのまま有効なので、書き直さなくて大丈夫です」と伝えます。

本人に「新しく気になっている点を、思いつくだけ書いてください。0個でも『ない』で大丈夫です」と聞きます。答えはそのまま記録します。言い換えたり、まとめたりしません。

## 3. 観点役を並列に動かす

本人の答えを受け取ったら、4人の観点役サブエージェントを1つのメッセージで同時に呼びます。

- `first-timer`（初見の客）
- `breaker`（壊し屋）
- `money-ops`（お金と運用）
- `misreading`（読み違い）

渡すのは、作るものの説明、資料の場所、known.items（前回までに出た項目）だけです。本人の今回の答えは渡しません。観点役が本人の答えに引っ張られず、独立して出すためです。known.items と同じ論点は出さないよう伝え、繰り返しではなく新しい角度を探させます。

観点役が見つからない環境では、general-purpose のサブエージェントに同じ役割を書いて渡します。

## 4. ヒントで追加を聞く

観点役を待つ間に、手順2で取ったヒントを見せます。

- ヒントがあれば、各ヒントの text をそのまま見せて「ほかに思いついたら一言どうぞ。なければ『ない』で」と聞きます。ここで出た答えは、ヒントのおかげで出たものとして区別します。
- ヒントがなければ（初回、または自分で出せるようになった観点だけのとき）、この手順は飛ばします。

## 5. 突き合わせる

観点役の結果を集め、似たものはまとめます。全体で最大12個までにします。

各項目について、本人の答えに同じ論点があるかを判断します。

- 同じ論点なら、本人の答えから一字一句そのままの引用を `quote` に入れます。
- 同じ単語に触れただけなら、同じ論点としません。
- 迷ったら空文字にします。

各項目には、題材に依存しない言い方の型を `pattern` に全角20字以内で付けます（例:「別アプリの手順が混ざる」→「似たもの同士の情報が混ざる」）。次の周回のヒントでは、この型だけを見せます。

次の形のJSONを一時ファイルに書き、`node scripts/notebook.mjs record <ファイル>` を実行します。

```json
{
  "project": "作るもの",
  "summary": "説明を1〜2文",
  "confidenceBefore": 100,
  "hintsShown": ["見せたヒントの文"],
  "own": [{ "text": "本人の答えそのまま", "phase": "free" }, { "text": "ヒントのあとの答え", "phase": "hint" }],
  "items": [{ "lens": "breaker", "item": "検討事項", "pattern": "題材に依存しない型", "why": "理由", "check": "確かめ方", "quote": "本人の答えからの引用、なければ空文字" }]
}
```

引用が本人の答えに実在するかはスクリプトが確かめます。実在しない引用は、AIだけが出したものとして扱われます。

## 6. 結果を見せる

スクリプトの出力をもとに、次の順で短く見せます。

1. 自分で出せていたもの
2. 自分だけが出したもの（AIは出せなかったもの）
3. ヒントで出せたもの
4. AIだけが出したもの（観点名、項目、確かめ方）

評価や説教はしません。「自分だけが出したもの」があれば、それも本人の強みとして伝えます。

最後に1つだけ聞きます。「今の自信は何%ですか？ やるものがあれば番号で教えてください（なくても大丈夫です）」。

答えを次の形で一時ファイルに書き、`node scripts/notebook.mjs update <ファイル>` を実行します。decisions の値は do（やる）、done（もう対応済み）、skip（やらない）、later（あとで）のどれかです。

```json
{ "id": "c1", "confidenceAfter": 80, "decisions": { "a1": "do", "a3": "skip" } }
```

## 7. 観点帳

観点帳のツリーと伸びは、pdcaai のリポジトリで `npm start` を実行し、`http://localhost:3210/#/notebook` で見られます。周回を重ねるほど、ヒントは減っていきます。
